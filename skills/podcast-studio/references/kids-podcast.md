## 1. 全流程总览

```
对标拆解 → 版权确认 → 全书分集大纲（用户确认门禁）
→ 第1集风格打样（迭代定调）→ 提示词模板固化
→ 批量量产（读原文→提取情节链→原创表达→字数校验→安审→交付）
→ 进度表 + 记忆同步
```

两种子模式：
- **章回体长篇**（西游记/三国/水浒）：重分集方法论，集间钩子连环
- **短篇集洗稿**（格林/安徒生/伊索）：重"思想与表达二分法"，单篇独立闭环

## 2. 版权与素材前置（N1）

- **公版判断**：作者卒年 + 50 年（吴承恩✅ 安徒生1875✅ 格林兄弟1863✅；神笔马良/小马过河 1955 年作品 ❌ 排除）
- **译本陷阱**：原著公版 ≠ 译文公版。例：叶君健 1999 年去世，译文版权到 2049 年。规则：读译文提取情节链 → 用自有品牌风格重新原创表达，绝不贴译文句子改词
- **对标红线**：凯叔/央视动画等改编作品有版权——结构和思路可借鉴，台词文稿绝对不抄
- **素材实测**：当场抓取公版原文验证可稳定获取（维基文库/用户提供的全文 txt），不要只凭记忆写冷门篇目
- **思想与表达二分法**（洗稿核心）：核心情节、人物设定、故事走向 = 思想（自由）；具体讲述方式、细节编排、语言 = 表达（受保护，必须全新创作）

## 3. 分集方法论（N3）

**三层拆分：**
1. 宏观分段：按原著大结构切块（如西游记：大闹天宫 → 取经缘起 → 师徒组队 → 八十一难）
2. 事件单元制：一个完整冲突 = 一个系列（1-5 集），系列≤5 集，钩子悬太久孩子会弃
3. 单集设计：每集 10 分钟（1900-2300 字）上限 15 分钟，内部起承转合闭环，结尾留钩子

**高光判断标准**（每集至少 1 个）：情节张力强 / 幽默好玩 / 情感浓度高 / 家长认知度高（搜索词=名场面）

**三标记法**：★保留（名场面/经典台词/笑点/情感点）｜✂删减（血腥/复杂宗教因果/重复套路/成人向）｜📌知识（成语典故地理，穿插叙述不单独成段）

**弱内容处理**：删除时保留一句桥接（剧情不断线）；多回可合并；超长集可拆上下（如 E04上/E04下，后续集号顺延需同步大纲）

**伏笔闭环**：跨集人物线要回收（如通天河老鼋托付问寿 → 结局集翻船回收）

## 4. 风格打样与模板固化（N4/N5）

打样要点（历史经验：第1集通常需 3-5 版迭代）：
- 先确认目标年龄段再定词汇档位：5-7 岁奶一点 / 6-10 岁口语不低幼 / 6-12 岁保留"读名著"获得感
- 语气词密度、拟声词数量、是否穿插解读，都是用户审美项，逐个确认
- 定稿后立即固化：开场固定句式、前情回顾规则（30秒内只接上集钩子）、收尾模板

**已验证的句式资产（可直接复用或换皮）：**
- 开场：「小朋友们，欢迎来到【品牌名】，我是XXX。今天给大家讲的是——《作品名》的第X集：集名！」（仅第1集加作品地位介绍，第2集起接前情回顾）
- 晚安版开场钩子：「故事的主人公是……大家一定好奇，……？一切，都要从……说起……」
- 晚安版收尾：「小朋友们，今天的故事就讲到这里。夜色慢慢安静下来啦，放下所有好奇，安心睡个好觉。祝你们拥有温柔好梦，我们下次再见，晚安。」
- 悬念收尾：留白提问 + 下集预告，一气呵成，不要"下期再见"式广播腔

## 5. 单集量产流水线（N6）

每集固定动作（单篇约 1-2 分钟）：
1. 读大纲确认本集范围/高光/上下集钩子
2. 读原文（公版原文或用户提供文本），提取情节链
3. 按基准风格原创表达（不是翻译，是"讲清楚为什么+用孩子懂的东西打比方"）
4. 字数校验：1900-2300 字 ≈ 10 分钟；不足则补原著细节扩写（不要注水）
5. 过安审 12 条（见第 6 节），出审核报告
6. 交付文件 + 更新进度表 + 记录恢复点

批量模式：用户说"继续"就连产，不问不停；每集交付附剧情摘要 + 安审结论。

## 6. 儿童安审 12 条（N7）

每篇必过，输出标准审核报告（格式见 `assets/templates/安审报告模板.md`）：

| # | 检查项 | 要点 |
|---|---|---|
| 1 | 暴力虚化 | 无血腥/伤害细节，打斗喜剧化 |
| 2 | 犯罪必反 | 负面行为必须有后果+定性旁白 |
| 3 | 迷信神话化 | 神仙妖怪=民俗神话表达，非求神拜鬼主线 |
| 4 | 情绪正向 | 悬念积极不惊悚，结局落正向价值观 |
| 5 | 关系安全 | 无早恋渲染；吻一律虚化为额头轻吻 |
| 6 | 语言净化 | 无不文明用语 |
| 7 | 无导流 | 无联系方式/诱导行为 |
| 8 | 恐怖零渲染 | 不营造恐怖氛围 |
| 9 | 无邪典魔改 | 正向改编，不恶搞经典 |
| 10 | 负向最小化 | 负面铺垫最简，正向结果最大 |
| 11 | 风险定级 | P0删除/P1改写/P2弱化/P3记录并改/P4记录 |
| 12 | 避野史猎奇 | 名著正典，不用野史噱头 |

**豁免判定**：经典童话幻想设定（巫婆/魔法）非迷信主线可豁免；校园霸凌类客观描述+正向结果可豁免。
**准入红线**：系列定位/上架标签不能用"晚安故事"（平台准入排除），定位用「经典童话改编/睡前童话」。

## 7. 红线改编方案库（踩坑沉淀，持续追加）

| 原著红线 | 标准改法 |
|---|---|
| 砍头/砍脚/火刑 | 删除刑罚，改为夺回宝物/烧掉鞋子/仙女现身化解 |
| 绞刑/刑场 | "重重惩罚他"/"被带到广场中央" |
| 主角死亡（猫吃老鼠） | 老鼠识破离开 + 猫后悔反思 |
| 厌世台词（"弄死我吧"） | 改积极行动表达（"我也要游到它们身边"） |
| 宗教叙事（圣母/天堂/洗礼） | 去宗教化：森林仙女/云中宫殿/满月酒 |
| 吸烟 | 改为许愿等非烟动作 |
| 自杀/死亡结局 | 受伤+悔改+团圆，恶有恶报喜剧化（狼掉井→爬出逃走） |
| 性别暗示（同眠） | 睡床边小凳 |
| 地域刻板（土耳其睡衣拖鞋） | "遥远的国家" |

## 8. 快速复刻经典 IP：五件套

任何新 IP 按此顺序落地（安徒生/格林已验证，半天到两天完成冷启动）：

1. **版权前置**：卒年+50 判断 → 译本陷阱排查 → 素材实测抓取
2. **篇目盘点**：解析全书结构出全量清单 → 适配评估（名篇优先，弱篇标改编思路）→ 建进度表
3. **分集大纲**：套分集方法论 → **用户确认后才进文稿**
4. **打样固化**：第1集迭代定调 → 提示词模板+固定句式+基准稿三件套
5. **批量量产**：固定流水线 + 进度表同步；红线篇目按方案库重构，不跳过（"每个故事都写"）

复刻时不可省略：风格基准稿（量产一致性来源）、大纲确认门禁（返工防线）、进度表同步（断点续产能力）。

候选公版 IP 池：三国/水浒/封神（章回体模式）、伊索寓言/一千零一夜（短篇模式+单篇扩写）、史记故事（讲史评书补充线）、聊斋（需重度重构，作压力测试）。
