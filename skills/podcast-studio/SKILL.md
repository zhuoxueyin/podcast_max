# Podcast Studio · AI 播客创作流水线

将"定方向 → 打样 → 模板固化 → 量产 → 质检 → 交付"的播客生产方法固化为可复用流程。所有项目共享同一套主干节点，按创作类型路由到差异化工作流。

## 意图路由

根据用户意图选择工作流，读取对应 reference 后执行：

| 用户意图 | 工作流 | 读取 |
|---|---|---|
| 儿童故事、亲子话本、名著儿童化（西游记/三国）、童话改编、晚安故事 | **亲子播客** | [references/kids-podcast.md](references/kids-podcast.md) |
| 音乐电台、OST盘点、歌手/年代专题、影视原声栏目 | **音乐播客** | [references/music-podcast.md](references/music-podcast.md) |
| 已有文稿转音频、播客配音、TTS | **音频生成** | [references/minimax-t2a.md](references/minimax-t2a.md) + `scripts/minimax_tts.py` |
| 新 IP/新栏目复刻（"用同样套路做 XX"） | 走对应类型工作流的"复刻五件套"段 | 同上 |
| 意图不明 | 先问一句确认类型与目标受众，不要猜 | — |

## 共享主干节点（所有工作流复用）

```
N0 意图识别与立项   → 定栏目定位、目标受众、单集时长
N1 版权与素材前置   → 公版判断/译本陷阱/对标红线/素材实测可得
N2 内容资产盘点     → 全书/选题全量清单 + 生产进度表（断点续产的地基）
N3 大纲/选题规划    → 产出后必须用户确认，再进生产（返工门禁）
N4 风格打样        → 第1期迭代定调（通常3-5版），定稿即风格基准
N5 模板固化        → 提示词模板 + 固定句式 + 基准稿（量产一致性来源）
N6 批量量产        → 单集流水线，批量模式"不问不停"
N7 质检门禁        → 亲子线过安审12条；音乐线过事实核实清单
N8 音频合成        → MiniMax T2A（scripts/minimax_tts.py）
N9 交付与状态同步   → 文件交付 + 进度表更新 + 记忆归档恢复点
```

执行纪律（从实战踩坑沉淀，务必遵守）：

1. **大纲确认是硬门禁**：分集/选题方案未经用户确认，不得进入批量写稿。
2. **风格基准稿必须存在**：没有定稿第1期就不量产；每次生产前对照基准稿，交付前核对格式一致性。
3. **人守三闸门**：方向定位、风格审美、最终发布由用户拍板；AI 产出到"待审核"状态停下，用户说"发"才流转。
4. **版权只减不增**：公版原著自由用；译本文字不照搬（取思想、重写表达）；对标作品借结构不抄文稿。不确定时先声明再请用户确认。
5. **每集闭环**：单集内部有完整满足感，系列间用钩子衔接；进度表逐集登记（集号/状态/高光/恢复点）。
6. **断点续产**：用户说"继续"时，先读进度表与记忆，汇报当前状态（已交付/恢复点/上一期结尾钩子）再开工。

## 目录结构

```
podcast-studio/
├── SKILL.md                        ← 本文件（路由 + 主干节点 + 纪律）
├── references/
│   ├── kids-podcast.md             ← 亲子播客完整工作流（含安审12条、复刻五件套）
│   ├── music-podcast.md            ← 音乐播客完整工作流（含选曲版权、事实核实清单）
│   └── minimax-t2a.md              ← MiniMax T2A 接口要点与播讲文本规范
├── scripts/
│   └── minimax_tts.py              ← T2A 合成脚本（长文本分段/发音词典/停顿时长）
└── assets/
    └── templates/
        ├── 分集大纲模板.md          ← N3 产出格式
        ├── 文稿生成提示词模板.md     ← N5 亲子线提示词骨架
        ├── 安审报告模板.md          ← N7 亲子线质检格式
        ├── 音乐播客文稿模板.md       ← N5/N6 音乐线文稿结构
        └── 生产进度表模板.md         ← N2/N9 状态登记格式
```

## 快速开始

- "帮我做西游记儿童话本" → 读 `references/kids-podcast.md`，从 N1 版权确认开始走
- "做一期王心凌OST盘点" → 读 `references/music-podcast.md`，从选题与选曲版权验证开始
- "把这集文稿转成音频" → 运行 `python scripts/minimax_tts.py 文稿.md -o E01.mp3`
- "照西游记的套路做三国演义" → 读 `references/kids-podcast.md` 的"复刻五件套"段
