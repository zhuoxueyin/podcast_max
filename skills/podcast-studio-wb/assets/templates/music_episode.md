# 音乐播客文稿模板

> 适用：音乐故事、歌手专题、OST 盘点等。

## 单期结构

```
【标题】有钩子、有年代感
【简介】一句话定位 + 情绪引入
【选曲清单】过渡曲 + 讲解曲(1~N) + 收尾曲（标版权 fee）
【开场钩子】(≤100字)
【事件还原】(故事背景 + 人物经历，杜绝幻觉)
【歌曲讲解】(每首：冷知识 / 词曲作者 / 歌曲故事)
【结语】(情感升华 + 互动引导 + 订阅引导)
```

## 标题公式

- 歌手《专辑》：XX年前，XXXX
- 199X年：XXX
- 例："2004年：一个沙哑的嗓子，把整个华语歌坛吵醒了"

## 开场钩子模板（≤100字）

```
有没有那么一段前奏，一响起来，你就又变回了……？
今天这期，我们聊聊……。
```

## 事件还原要点

- 时间、人物、背景故事准确（杜绝幻觉）
- 有高潮片段可前置于事件还原之前（交叉淡入）

## 歌曲讲解要点

- 每首曲讲：冷知识、词曲作者、歌曲故事、人物经历
- 人声占比默认 20%，可要求 30%（更多解读）

## 结语模板

```
从……到……，我们跟着这些旋律，走过了……。
如果你也想起了……，欢迎在评论区告诉我。
也别忘了订阅XXX，我是XX，我们下期见。
最后这一首，留给……。
```

## 完整示例（宫崎骏×久石让 片段）

```
【标题】《宫崎骏×久石让》— 这些旋律一响，你就回不去了

【开场钩子】
有没有一段旋律，你一听就知道自己几岁、在哪个房间、和谁在一起？

【事件还原】
宫崎骏画画，久石让写音，四十年里，他们一起造出了一个所有人共享的童年。

【歌曲讲解】
（每首：为什么《天空之城》前奏一响，成年人的眼泪就下来了？）

【结语】
如果这一期里有那么一段旋律让你突然想家，欢迎在评论区告诉我……
也别忘了订阅OST时光机。我是欢欢，我们下期见。
```

## 作者声明（每期必加）

