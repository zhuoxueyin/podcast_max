# 亲子播客 · 短篇童话洗稿文稿模板

> 适用：安徒生/格林等童话、寓言。品牌固定句式，钩子开头 + 哄睡收尾。

## 单篇结构（三段式）

```
【开场】一句话直入 + 情绪钩子
【正文】零打断，原创洗稿（思想层提取 + 全新表达）
【收尾】哄睡感 + 主题点题 + 晚安
```

## 开场模板

```
小朋友们，晚上好呀！欢迎来到【海螺晚安故事】，我是神奇海螺。
今晚海螺给大家讲的故事，叫《XX》。

故事的主人公，是……。大家一定好奇，……？
一切，都要从……说起……
```

**情绪钩子要点**：点题有画面感、不剧透、引入句有场景感（如"踏上回家路途那一刻""织布匠走进王宫那天"）。

**系列第一篇额外加**（格林童话首篇示例）：
```
从今天开始，我们要讲《格林童话》啦！格林童话呀，是德国的格林兄弟，
走遍乡村，从老百姓口中收集来的民间故事，全世界的小朋友都爱听。
```

## 正文要求

- 零打断，约 2000~2300 字
- 原创洗稿：只提取情节思想，用海螺风格全新表达，不贴译本文字
- 红线内容按"儿童保护 > 文学性 > 原著还原"重构（见 shenhe_rules.md）

## 收尾模板（哄睡版）

```
小朋友们，今天的故事就讲到这里。
（一句话点题，如"分享和礼貌，从来不会白费"）
夜色慢慢安静下来啦，放下所有好奇，安心睡个好觉。
祝你们拥有温柔好梦，我们下次再见，晚安。
```

## 完整示例（打火匣 片段）

```
小朋友们，晚上好呀！欢迎来到【海螺晚安故事】，我是神奇海螺。
今晚海螺给大家讲的故事，叫《打火匣》。
故事的主人公是一名士兵。大家一定好奇，他究竟是怎样得到神奇打火匣的？
一切，都要从他踏上回家路途的那一刻说起……

（正文：从前，有一个士兵……）

小朋友们，今天的故事就讲到这里。
善良的人，运气不会太差——你分出去的面包，会变成金子回来的。
夜色慢慢安静下来啦，放下所有好奇，安心睡个好觉。
祝你们拥有温柔好梦，我们下次再见，晚安。
```
