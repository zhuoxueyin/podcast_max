# 亲子播客 · 长篇连载单集文稿模板

> 适用：名著改编连载（西游记、三国等）。第 1 集与后续集开场略有差异。
> 当前标准：**角色化剧本稿**（每集按旁白/角色逐行整理 + 音效/背景音 cue），供多角色配音与混音直接取用。

## 单集结构（三段式，在剧本稿中以注释章节呈现）

```
# 开场  固定句式 + 第X集：集名 + 上集回顾（第2集起）
# 正文  零打断，纯故事（不穿插解读/说教）
# 收尾  悬念提问 + 下集预告，一气呵成
```

## 角色化剧本稿格式（Exx 文稿统一标准）

```
# 《节目名》第 X 集 · 剧本稿（角色配音版）
# 集名：… | 主题：… | 原著对应：… | 目标字数/时长：…
# 本集出场角色：旁白、阿慢、跳跳、…
# 音色表 旁白=female-chengshu;阿慢=male-qn-jingying;跳跳=female-shaonv;…   ← 必备，分号分隔

[[BGM:主题名]]          ← 背景音乐控制：整集铺底自动淡入淡出，可随时切换

【旁白】文字…（叙述/场景/动作/心理，一行一句或一段）
【阿慢】台词…
【跳跳】台词…

[[SFX:文件名键]]        ← 音效 cue：放在上一句结束后、下一句之前（不叠人声）

【旁白】……
---
```

### 规则
1. **角色逐行规整**：叙述归【旁白】；台词归对应角色；严禁无角色标记的裸文字行。
2. **角色名与音色表一致**，未注册角色会报错提醒（需先加入音色表）。
3. `#` 开头为注释（元信息/分段标注），不朗读；`---` 分隔线跳过。
4. 音效 cue 每集 5~8 处，句与句之间插入；BGM 铺底，音量默认 -16dB 自动处理。
5. 角色情绪靠台词与语气词；MiniMax 2.8 文本内语气标签 `(laughs)(chuckle)(sighs)` 偶用。
6. 知识讲解藏在角色对话/旁白叙述中，不单独开课、不跳出角色说教。

## 角色音色（权威映射，由项目级文件维护）

- 每个 IP 项目根目录维护一份 **`00_角色音色表.md`**：角色↔音色唯一事实源，含「机器读区 / 常驻角色卡 / 临时音色池 / 更换音色 SOP / 变更记录」。
  完整示例：见《乌龟兔西游历险记》项目根同名文件。
- 单集剧本稿头部「音色表」行 = 从该文件「机器读区」**复制本集出场角色的映射**（脚本自包含、单集可直接跑）。
- **更换音色 / 全系列统一改音色**：只改 `00_角色音色表.md`，然后带 `--voice-map` 重跑：
  `python scripts/tts_cast.py --script Exx.md --assets 素材 --voice-map 00_角色音色表.md --out Exx_终混.mp3`
  脚本按音色指纹只重新合成受影响角色的语音段，其余段走缓存。
- 参考写作卡：人物性格/说话特点固化在各 IP 系列大纲「角色卡」章节；音色不在模板/大纲里另存，避免两处漂移。

## 第 1 集开场模板（口语引导腔）

```
小朋友们，欢迎来到《乌龟兔西游历险记》！
我是见多识广、又稳又帅的乌龟——阿慢。
我是蹦蹦跳跳、天下第一可爱的兔子——跳跳！
（仅第1集交代穿越缘起与名著地位）
```

## 第 2 集起开场模板

```
小朋友们，欢迎来到《乌龟兔西游历险记》！
上一集，阿慢和跳跳帮石猴当上了水帘洞的美猴王。
可这一集——他们一睁眼，发现自己又钻进了新的故事！
```

## 正文要求

- 零打断、零解读、零说教
- 口语化但不奶声奶气，词汇适度升级（名副其实/心照不宣/别有洞天）
- 语气词密度低，拟声词 3~5 处点缀（拟声处可配 SFX）
- 约 2000~2300 字（≈10 分钟）

## 收尾模板

```
小朋友们，你们猜——（悬念提问，呼应本集结尾）？

（下集预告 2~3 句，一气呵成，无"下期再见"式广播腔）
```
