# 质检合规规则（安审 12 条 + 判例库 + 版权红线）

## 一、儿童内容安审 12 条清单

每篇亲子播客文稿必过以下 12 条：

| # | 检查项 | 说明 |
|---|---|---|
| 1 | 暴力虚化 | 无伤害/血腥细节描写 |
| 2 | 犯罪必反 | 犯罪行为必须有负向定性 |
| 3 | 迷信神话化 | 民俗神话可用（开头标"传说"），非求神拜鬼主线 |
| 4 | 情绪正向 | 悬念积极不惊悚 |
| 5 | 关系安全 | 无爱情线/早恋渲染 |
| 6 | 语言净化 | 无不文明用语 |
| 7 | 无导流 | 无联系方式/诱导 |
| 8 | 恐怖零渲染 | 恐怖氛围不渲染 |
| 9 | 无邪典魔改 | 正向改编 |
| 10 | 负向最小化 | 无反面教材情节，负向有后果 |
| 11 | 风险定级 | P0/P1/P2/P3/P4 分级 |
| 12 | 避野史猎奇 | 名著正典，非野史 |

**风险定级**：
- **P0**：红线，必改（血腥砍杀、火刑、自杀、杀害至亲、宗教核心叙事）
- **P1**：红线，必改（死亡暗示、民族歧视、低俗两性、厌世）
- **P2**：必改（轻微暴力、宗教表述、吸烟饮酒、欺骗）
- **P3**：建议改（轻微恐怖感、不当用语）
- **P4**：记录即可（童话惯例、可接受的价值观铺垫）

**处理原则**：**儿童保护 > 文学性 > 原著还原**

**三种处理策略**：
1. **弱化**：血腥/暴力虚化
2. **删除**：宗教、成人内容整体删除
3. **重构**：无正向内核时改编成新故事

**豁免判定**：经典童话幻想设定（巫婆/魔法/仙女）不属"算命求签"类封建迷信；王子公主结婚是童话惯例（但需"额头亲"级别，无爱情渲染）；校园霸凌客观呈现 + 正向结果可豁免。

## 二、安审判例库（直接复用）

### 死亡 → 离开/远行

| 原著 | 处理 |
|---|---|
| 猫吃老鼠 | 老鼠识破真相伤心离开 + 猫后悔反思 |
| 狼掉井淹死 | 掉井→抓井绳爬出→灰溜溜逃走 |
| 女巫被推进火炉 | 变乌鸦飞走（去死亡化） |
| 跳蚤当兵牺牲 | 去了很远很远的国家 |
| 老爷爷离世 | 老爷爷离开农庄去远方（赠书） |

### 血腥/自残 → 轻伤/无害

| 原著 | 处理 |
|---|---|
| 砍脚（红鞋） | 脚底磨破 + 摔跤磕破膝盖（轻伤） |
| 切脚趾/削脚跟（灰姑娘） | 脚太大/脚后跟胖塞不进 |
| 切手指开门（七只乌鸦） | 用发卡撬锁孔 |
| 杀蛇（三片蛇叶） | 意外被落石压住 |
| 开膛救羊（狼和七只小山羊） | 保留（正向救援，无血腥细节） |
| 猴"摔成肉泥" | "跳进去可不是闹着玩的" |

### 宗教 → 世俗化

| 原著 | 处理 |
|---|---|
| 教皇/弥撒/圣餐 | 女元帅/庆典 |
| 圣母玛利亚/天堂/天使 | 森林仙女/云中宫殿/小精灵 |
| 上帝/感谢上帝 | 阳光/大自然/删除 |
| 魔鬼的黑城堡 | 魔王的黑城堡（去宗教，保留奇幻） |
| 花中的安琪儿 | 花王子/小精灵 |

### 暴力/杀戮 → 赶走/化解

| 原著 | 处理 |
|---|---|
| 父亲命仆杀儿子 | 赶出家门自谋生路 |
| 杀鹿取眼舌 | 删除 |
| 打死猫狗 | 放到门外/举斧吓唬 |
| 火刑/沸油桶 | 送出王宫 |
| 钉桶滚河 | 赶出王宫 |
| 砍孩子头颅复活 | 真诚悔悟+眼泪解除魔法 |

### 成人/低俗 → 儿童化

| 原著 | 处理 |
|---|---|
| 衬衫领子逐一求婚调情 | 吹牛被揭穿 |

| 抽烟 | 擦打火匣许愿 |
| 犹太人贪婪形象 | 贪心的商人（去民族歧视） |

## 三、洗稿版权红线

1. **公版原著**（西游记/格林/安徒生故事本身）：情节思想自由使用
2. **有版权译文**（叶君健译安徒生，版权到 2049 年）：必须提取思想 + 全新表达，不贴译文句子
3. **有版权改编**（凯叔/央视动画）：只能借鉴结构，不能抄台词文稿
4. **现代作品**（神笔马良/小马过河 1955 年）：有版权，排除

**合规洗稿 = 思想层提取 + 原创表达**（猫和老鼠案例：核心创意可自由用，具体情节设计和语言描述是受保护表达）

## 四、音乐播客准确性质检

- 封面描述、年代、人物故事逐项核实
- 检查表述是否过于绝对
- 年份、多音字播讲细节
- 多音字替换规则：港乐→香港歌坛、乐坛→歌坛（先换"乐坛"再换"港乐"）
