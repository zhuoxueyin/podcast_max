# 亲子播客创作 Workflow

亲子播客本质是「经典 IP 儿童化改编流水线」。根据素材类型分为两种模式，共享同一套底层逻辑（安审、模板、进度管理）。

---

## 模式 A：长篇 IP 连载改编（名著）

适用：西游记、三国演义、水浒传、封神榜等公版名著，做成连载儿童故事。

### 完整流程（六步）

```
S0 选题定版 → S1 对标分析 → S2 全书分集大纲 → S3 单集文稿 → S4 安审 → S5 存档管理
```

### S0 选题定版

- 确认改编对象 + 版权状态（公版原著可直接用原文情节；凯叔/央视等改编作品有版权，只能借鉴结构不能抄台词）
- 确认目标年龄（默认 **6~12 岁**：口语但不奶声奶气、有信息密度、有"读名著"的获得感）

### S1 对标分析（可选但推荐）

- 抓取 2~3 个同赛道头部对标节目，转写实测，拆解结构、时长、手法
- 产出「对标分析报告」+ 手法清单（如"语言翻译术、现代类比法、即时词条解释、背景前置、悬念钩子、命名SEO"等）

### S2 全书分集大纲（关键前置步骤）

**必须先出大纲、用户确认后，才动笔写文稿。**

核心三条分集方法论：
1. **事件单元制**：一个完整冲突 = 一个系列（1~5 集），每集 5~10 分钟
2. **单集也要闭环**：每集内部有起承转合，结尾留钩子
3. **高光优先**：先做名场面集，普通过渡情节后补

**每集标准**：单集 10 分钟（上限 15min，约 2000~2300 字）；每集至少一个 ★ 高光；结尾必留悬念；知识点穿插在叙述中（不单独开课）。

**分集大纲表字段**：
`系列 | 集号 | 原著范围(第几回) | 核心情节 | 高光标记★ | 单集时长 | 结尾悬念 | 删减/简化说明`

**删减三标记法**：
- ★ 保留（名场面/经典台词/笑点/情感点）
- ✂ 删减（血腥、复杂宗教、重复套路、成人向暗示）
- 📌 知识（成语典故/历史地理，穿插简述）

### S3 单集文稿（固定模板）

三段式结构（详见 `assets/templates/qinzi_episode.md`）：

```
【开场】固定句式 + 第X集：集名 + 上集回顾（第2集起）
【正文】零打断，纯故事（不穿插解读/说教）
【收尾】悬念提问 + 下集预告，一气呵成
```

**关键约束（已从实际项目迭代定型）**：
- 开场固定句式：「小朋友们，欢迎来到【海螺学堂】，我是无所不知的神奇海螺。今天海螺要继续给大家讲的是——《西游记》的第X集：集名！」
- 第 1 集开场额外加"名著地位介绍"（仅第 1 集），第 2 集起改为"上集回顾"（30 秒内，只接上集结尾钩子）
- 正文零打断、零解读、零说教，知识点集中到结尾快速带过
- 收尾去"下期再见"式广播腔，改为悬念 + 预告一气呵成
- 语气词密度低、词汇适度升级（名副其实/心照不宣/别有洞天）、拟声词 3~5 处点缀

### S4 安审

过 12 条儿童内容安审清单，详见 `references/shenhe_rules.md`。每篇出审核报告。

### S3.5 角色固化与角色化剧本稿(推荐标准)

- **项目级权威音色表**:每个 IP 项目根维护 `00_角色音色表.md`,角色↔音色唯一事实源(含常驻角色卡 / 临时音色池 / 更换音色 SOP / 变更记录)。音色映射不在大纲、模板里另存。
- **角色卡在大纲层固化**:角色=身份/性格/说话特点,单集不得改;临时角色进「音色池」按集选配。
- **单集文稿=角色化剧本稿**:按「旁白/角色」逐行整理 + `[[SFX:名]]` / `[[BGM:名]]` cue。模板见 `assets/templates/qinzi_episode.md`。
- 每集稿头「音色表」行从权威表「机器读区」复制;开头第 1 集示例可直接套用乌龟兔/海螺等 IP 固定开场句式。
- **角色音色取用三通道(按优先级 A→B→C,voice_id 一律回填权威表后贯穿全系列)**：
  - ① 现成系统音色(首选,快):`scripts/tts_minimax.py --voice <系统ID>` 直试,够贴角色即启用
  - ② 描述生成(Voice Design):`scripts/voice_design.py --prompt "<声音描述>" --preview "<典型台词≤500字>" --out 试音.mp3` → 返回 `ttv-voice-…`
  - ③ 声音复刻(Voice Clone):手上有**已授权**人声素材(10s~5min)时 `scripts/voice_clone.py --audio <素材> --voice-id <自定义ID> --text "<试听台词>" --out 试音.mp3` → 自定义 voice_id(如 `SunWuKong_Classic_20260906`);可选 `<8s` 示例音频 + `--prompt-text` 提升相似度
  - 三通道产出的 voice_id 与系统音色等价,可直接用于 `tts_minimax.py` / `tts_cast.py` 正式合成(详见 `references/minimax_api.md`「声音复刻」与「音色能力总览」)

### S4.5 音频生成(分角色配音+混音)

```
角色化剧本稿(md)
  → python scripts/tts_cast.py --script Exx.md --assets 素材目录 \
      --voice-map 00_角色音色表.md --out Exx_终混.mp3
      (内部:按角色分段 TTS → 纯语音拼接 → BGM/SFX 对位混音;
       --voice-map = 用项目权威角色音色表统一/覆盖角色音色,换音色只改该表重跑即可)
  → 产出 Exx_纯语音.mp3(可选) + Exx_终混.mp3
```

- BGM/SFX 素材可程序合成(`scripts/make_sfx.py --out 素材目录`)或放真实采声同名 wav 替换。
- 素材放各集 `素材/` 目录;配音段缓存文件名含「音色指纹」,换音色后只有受影响角色的段落重新合成、其余秒过缓存,失败重跑自动续。
- 音效每集 5~8 处,句间插入;BGM 默认 -16dB 铺底、自动淡入淡出。

### S5 存档管理

- 建生产进度表：`集号 | 状态(已交付/待做) | 恢复点 | 改编备注`
- 存长期记忆，支持"随时中断、下次续作"（恢复点机制）

## 模式 B：短篇童话洗稿

适用：安徒生童话、格林童话、伊索寓言等公版短篇集。

### 完整流程

```
读原文 → 提取情节链(思想) → 原创洗稿(重写表达) → 安审重构 → 交付
```

### 核心：洗稿方法论（版权合规红线）

**思想 vs 表达二分法**：
- 著作权只保护"表达"，不保护"思想"
- 核心创意/情节/人物设定/故事走向 = 思想，可自由使用
- 具体情节设计、细节编排、语言描述 = 表达，受保护

**三条铁律**：
1. 只提取情节链（思想层），用海螺风格完全重新原创表达
2. 绝不贴原文改词
3. 公版原著 vs 有版权译文的区别：安徒生故事本身公版（1875 年去世），但叶君健译本有版权（译文版权到 2049 年）→ 必须提取思想 + 全新表达，不能贴着译文句子改写

### 篇目筛选与统计

- 解析全量篇目，建「可做性统计表」：✅ 可单独成集 / ⚠️ 短篇需合并扩充 / 🔧 需去宗教化
- **对齐权威目录**（如格林童话用 KHM 1-210 标准编号），避免进度表越积越乱

### 文稿模板

详见 `assets/templates/qinzi_tale.md`。关键结构：
- 开场：一句话直入 + 情绪钩子（"故事的主人公是……大家一定好奇……一切，都要从……说起"）
- 正文：零打断
- 收尾：哄睡感（"夜色慢慢安静下来啦，放下所有好奇，安心睡个好觉。祝你们拥有温柔好梦，我们下次再见，晚安"）

### 安审重构原则

红线内容按 **"儿童保护 > 文学性 > 原著还原"** 原则处理，三种策略：
1. **弱化**：血腥/暴力细节虚化（"砍头"→"受伤"，"死亡"→"离开"）
2. **删除**：宗教、成人向内容整体删除（"教皇"→"女元帅"，"上帝"→"阳光/大自然"）
3. **重构**：无正向内核可提炼时，改编成新故事（成人讽刺→儿童成长主题）

判例库见 `references/shenhe_rules.md`。

## 两模式对比

| 维度 | 模式 A（长篇改编） | 模式 B（短篇洗稿） |
|---|---|---|
| 素材 | 单本公版名著 | 公版童话 + 有版权译文 |
| 版权处理 | 直接用原文情节 | 必须洗稿（思想提取 + 原创表达） |
| 分集 | 自己拆全书 | 一篇 = 一集 |
| 安审难点 | 暴力弱化 | 宗教/死亡/成人内容重构 |
| 节奏 | 连载追更 | 独立单集（晚安故事） |

---

## 复刻新 IP 的通用公式

```
复刻 = 对标分析 + 分集/筛选 + 固定模板 + 安审重构 + 进度管理
```

**复用三样资产，避免每次从头开始**：
1. **模板库**：换"集名/人物/情节"即可
2. **判例库**：安审红线处理方案直接套
3. **进度表范式**：统一字段结构照抄
